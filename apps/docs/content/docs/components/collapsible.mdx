## Features

- Controlled or uncontrolled.
- Height animation on open and close, removed with reduced motion.
- Built on [Radix Collapsible](https://www.radix-ui.com/primitives/docs/components/collapsible).

<Install />

## Anatomy

```tsx
import { Collapsible, CollapsibleContent, CollapsibleTrigger } from "@irisui/ui";

export default () => (
  <Collapsible>
    <CollapsibleTrigger />
    <CollapsibleContent />
  </Collapsible>
);
```

### CollapsibleTrigger

The button that toggles the content. Use `asChild` to render your own Button.
`data-state` is `"open"` or `"closed"`.
