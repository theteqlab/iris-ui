---
title: AspectRatio
description: Keeps content, such as an image or a video, at a given width / height ratio.
---

<Demo name="aspect-ratio/basic" />

## Features

- Any ratio: `16 / 9`, `4 / 3`, `1`.
- Follows the width of its container.
- Built on [Radix Aspect Ratio](https://www.radix-ui.com/primitives/docs/components/aspect-ratio).

## Installation

<Install />

## Usage

```tsx
import { AspectRatio } from "@irisui/ui";

export default () => (
  <AspectRatio ratio={16 / 9}>
    <img src="/lake.jpg" alt="A lake at dawn" className="size-full object-cover" />
  </AspectRatio>
);
```
