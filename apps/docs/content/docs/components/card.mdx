## Features

- Three surfaces: `glass` (default), `strong` (the film) and `ink`.
- Header, title, description, content and footer parts.
- `asChild` on the card (a link, an `<article>`) and on the title (to pick its level).

## Anatomy

```tsx
import { Card, CardContent, CardDescription, CardFooter, CardHeader, CardTitle } from "@irisui/ui";

export default () => (
  <Card>
    <CardHeader>
      <CardTitle />
      <CardDescription />
    </CardHeader>
    <CardContent />
    <CardFooter />
  </Card>
);
```

## API reference

### Card

Renders a `<div>`.

<PropsTable type="CardProps" pick={["variant", "asChild"]} />

| Data attribute | Values                         |
| -------------- | ------------------------------ |
| `data-variant` | `"glass" \| "strong" \| "ink"` |

### CardTitle

An `<h3>` by default.

<PropsTable type="CardTitleProps" pick={["asChild"]} />

### CardHeader, CardDescription, CardContent, CardFooter

Layout parts: `<div>`s, and a `<p>` for the description. The footer aligns its actions
to the end.

## Accessibility

A card is a layout container with no role. When it is a link, keep a single link
(`asChild`) rather than nesting interactive elements inside it.
