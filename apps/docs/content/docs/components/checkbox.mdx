## Features

- Its label is its children; the whole row is the 44 px click target.
- Checked, unchecked and indeterminate (`checked="indeterminate"`).
- Controlled or uncontrolled; submits with a form (`name`, `value`).
- Built on [Radix Checkbox](https://www.radix-ui.com/primitives/docs/components/checkbox).

## Accessibility

Follows the [WAI-ARIA checkbox pattern](https://www.w3.org/WAI/ARIA/apg/patterns/checkbox/):
`role="checkbox"` with `aria-checked` (`mixed` when indeterminate). Without a visible
label, set `aria-label`.
