title: IconButton

## Features

- The `aria-label` is required by the types: an icon alone has no accessible name.
- Square: 36, 44 or 56 px, with the 44 px target in `md`.
- Same `look`, `tone`, `loading` and `asChild` as [Button](/docs/components/button).

## Installation

<Install />

## Usage

```tsx
import { IconButton } from "@irisui/ui";

export default () => (
  <IconButton aria-label="Settings">
    <GearIcon />
  </IconButton>
);
```

## Accessibility

The `aria-label` names the button; the icon inside is hidden from assistive technology.
