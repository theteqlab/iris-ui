## Features

- Horizontal or vertical, 1 px in the theme's line colour.
- Decorative by default; announced as a `separator` when it divides sections.
- Built on [Radix Separator](https://www.radix-ui.com/primitives/docs/components/separator).

## Accessibility

A decorative separator is hidden from assistive technology. With
`decorative={false}`, it has `role="separator"` and its `aria-orientation`.
