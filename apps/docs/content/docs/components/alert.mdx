## Features

- Four tones: `info`, `success`, `warning`, `danger`.
- Warnings and errors are announced at once (`role="alert"`), the others politely
  (`role="status"`).
- Replace the icon, or hide it.

## Accessibility

An alert rendered with the page is read with the page; one added later is announced
according to its role. For a short-lived message, use a [Toast](/docs/components/toast).
The tone is never carried by colour alone: the icon and the text say it too.
