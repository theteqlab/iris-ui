## Features

- Typing moves to the next box, Backspace to the previous one.
- A pasted code, or one filled in by the phone, fills every box.
- Digits only by default; `validationType="alphanumeric"` for letters too.
- `autoSubmit` submits the form once the code is complete.
- Labels from `LocaleProvider` ("Character 1 of 6").
- Built on [Radix One-Time Password Field](https://www.radix-ui.com/primitives/docs/components/one-time-password-field) (preview).

## Usage

```tsx
import { Field, FieldLabel, OneTimePasswordField } from "@irisui/ui";

export default () => (
  <Field>
    <FieldLabel>Verification code</FieldLabel>
    <OneTimePasswordField />
  </Field>
);
```

## Accessibility

The boxes are a `group` named by the Field label, each one labelled with its position.
The code is also in a hidden input, submitted with the form under `name`.

<KeyboardTable
  keys={[
    ["Tab", "Moves to the first empty box, then out of the field."],

    ["ArrowLeft", "Moves to the previous box."],
    ["Backspace", "Clears the box, or moves back and clears the previous one."],
