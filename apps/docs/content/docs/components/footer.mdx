## Features

- Columns of links, each a named navigation landmark.
- A bottom row for the copyright, legal links or a theme switch.
- `plain` (on the page, with a top line) or `glass` (a frosted glass panel).
- A responsive grid: 2, 3 then 4 columns.

## Anatomy

```tsx
import { Footer, FooterBottom, FooterColumn, FooterColumns, FooterLink } from "@irisui/ui";

export default () => (
  <Footer>
    <FooterColumns>
      <FooterColumn title="…">
        <FooterLink href="…" />
      </FooterColumn>
    </FooterColumns>
    <FooterBottom />
  </Footer>
);
```

## Accessibility

The page's `<footer>` is its `contentinfo` landmark. Each column is a `<nav>` named by
its title, so screen reader users can jump to "Help" or "Legal" directly.
