## Features

- Focus is trapped inside and returns to the trigger on close.
- <kbd>Esc</kbd> and a click on the veil close it; both can be prevented.
- The page behind does not scroll.
- Title and description are announced when it opens.
- Controlled or uncontrolled; three widths.
- The close button label comes from `LocaleProvider` (English and French built in).

## Anatomy

```tsx
import {
  Dialog,
  DialogBody,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@irisui/ui";

export default () => (
  <Dialog>
    <DialogTrigger />
    <DialogContent>
      <DialogHeader>
        <DialogTitle />
        <DialogDescription />
      </DialogHeader>
      <DialogBody />
      <DialogFooter>
        <DialogClose />
      </DialogFooter>
    </DialogContent>
  </Dialog>
);
```

### DialogContent

The veil and the panel, rendered in a portal. Also takes every prop of
[Radix `Dialog.Content`](https://www.radix-ui.com/primitives/docs/components/dialog#content).

### DialogHeader, DialogBody, DialogFooter

Layout parts, plain `<div>`s. The header carries the holographic band and leaves room
for the close button; the body scrolls when the content is taller than the screen; the
footer aligns the actions to the end.

### DialogTitle, DialogDescription

Announced when the dialog opens. A title is required: hide it with a `sr-only` class
if the design has none. Both accept `asChild`.

### DialogClose

Closes the dialog. Use `asChild` to render your own `Button`.

## Accessibility

Follows the [WAI-ARIA dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/).
The panel has `role="dialog"` and `aria-modal`, labelled by `DialogTitle` and described
by `DialogDescription`. The close button is 44 px wide and labelled.
