## Features

- One Tab stop; arrow keys move between the controls.
- Buttons, links, toggle groups and separators, styled like [Toggle](/docs/components/toggle).
- Horizontal or vertical.
- Built on [Radix Toolbar](https://www.radix-ui.com/primitives/docs/components/toolbar).

## Anatomy

```tsx
import {
  Toolbar,
  ToolbarButton,
  ToolbarLink,
  ToolbarSeparator,
  ToolbarToggleGroup,
  ToolbarToggleItem,
} from "@irisui/ui";

export default () => (
  <Toolbar>
    <ToolbarToggleGroup type="multiple">
      <ToolbarToggleItem value="…" />
    </ToolbarToggleGroup>
    <ToolbarSeparator />
    <ToolbarButton />
    <ToolbarLink />
  </Toolbar>
);
```

## API reference

### Toolbar

`orientation` (default horizontal), `loop`, `dir`. See
[Radix `Toolbar.Root`](https://www.radix-ui.com/primitives/docs/components/toolbar#root).

### ToolbarToggleGroup, ToolbarToggleItem

Like a [ToggleGroup](/docs/components/toggle-group): `type`, `value` / `onValueChange`.

### ToolbarButton, ToolbarLink, ToolbarSeparator

A button, a link and a line between groups.

## Accessibility

Follows the [WAI-ARIA toolbar pattern](https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/).
Name it with `aria-label`, and each icon-only control too.
