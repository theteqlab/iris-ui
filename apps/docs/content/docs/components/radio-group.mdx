## Features

- Arrow keys move the choice; <kbd>Tab</kbd> enters and leaves the group.
- Inside a [Field](/docs/components/field), the `FieldLabel` names the group.
- Vertical or horizontal.
- Built on [Radix Radio Group](https://www.radix-ui.com/primitives/docs/components/radio-group).
