## Features

- Opens under its trigger, at least as wide, and stays on screen.
- Typeahead: type the first letters to reach an option.
- Groups, labels, separators and disabled options.
- The placeholder comes from `LocaleProvider` ("Select…" or "Choisir…").
- Takes its id, description and invalid state from its [Field](/docs/components/field).
- Built on [Radix Select](https://www.radix-ui.com/primitives/docs/components/select).

## Anatomy

```tsx
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectLabel,
  SelectSeparator,
  SelectTrigger,
  SelectValue,
} from "@irisui/ui";

export default () => (
  <Select>
    <SelectTrigger>
      <SelectValue />
    </SelectTrigger>
    <SelectContent>
      <SelectGroup>
        <SelectLabel />
        <SelectItem />
      </SelectGroup>
      <SelectSeparator />
    </SelectContent>
  </Select>
);
```
