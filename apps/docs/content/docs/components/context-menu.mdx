## Features

- Opens where the pointer is, with a right click or a long press on touch screens.
- Same items as the [DropdownMenu](/docs/components/dropdown-menu): checkbox and radio
  items, labels, separators, shortcuts, submenus, `variant="danger"`.
- Built on [Radix Context Menu](https://www.radix-ui.com/primitives/docs/components/context-menu).

## Anatomy

```tsx
import { ContextMenu, ContextMenuContent, ContextMenuItem, ContextMenuTrigger } from "@irisui/ui";

export default () => (
  <ContextMenu>
    <ContextMenuTrigger />
    <ContextMenuContent>
      <ContextMenuItem />
    </ContextMenuContent>
  </ContextMenu>
);
```

The other parts mirror the DropdownMenu: `ContextMenuCheckboxItem`,
`ContextMenuRadioGroup`, `ContextMenuRadioItem`, `ContextMenuLabel`,
`ContextMenuSeparator`, `ContextMenuShortcut`, `ContextMenuSub`, `ContextMenuSubTrigger`,
`ContextMenuSubContent`.

## Accessibility

Follows the [WAI-ARIA menu pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menubar/).
A context menu is hard to discover and cannot be opened from every keyboard: keep
another way to reach the same actions, such as a [DropdownMenu](/docs/components/dropdown-menu).
