## Features

- One thumb for a value, two for a range (from `value` or `defaultValue`).
- The range shows the holographic film, or a tone.
- 24 px thumbs, a 44 px tall touch area; horizontal or vertical.
- Takes its name from a [Field](/docs/components/field) label.
- Built on [Radix Slider](https://www.radix-ui.com/primitives/docs/components/slider).

## Usage

```tsx
import { Slider } from "@irisui/ui";

export default () => <Slider aria-label="Volume" defaultValue={[60]} />;
```

## Accessibility

Follows the [WAI-ARIA slider pattern](https://www.w3.org/WAI/ARIA/apg/patterns/slider/):
each thumb is a `slider` with its value. Name a single thumb with `aria-label` or a
Field label, and each thumb of a range with `thumbLabels`.
