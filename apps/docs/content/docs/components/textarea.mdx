## Features

- Grows with its content (`autoResize`) or is resized by hand.
- A character counter, announced politely, turning red at the limit.
- Invalid state from the `invalid` prop or from its [Field](/docs/components/field).

## Usage

```tsx
import { Field, FieldLabel, Textarea } from "@irisui/ui";

export default () => (
  <Field>
    <FieldLabel>Message</FieldLabel>
    <Textarea />
  </Field>
);
```

## Accessibility

The counter is linked to the field (`aria-describedby`) and announced politely as you
type. Its text, "12 / 160 characters", comes from `LocaleProvider` or `counterLabel`.
