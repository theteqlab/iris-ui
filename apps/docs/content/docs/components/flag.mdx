## Features

- Over 250 flags as SVG, sharp at every size: countries (ISO 3166-1 alpha-2) and
  subdivisions (`gb-sct`, `us-ca`).
- Three shapes (4:3, square, round) and three heights (16, 24, 32 px).
- Named after the country in the language of `LocaleProvider` ("Germany", "Allemagne"),
  by the browser: no list to maintain.
- The country code shows if the image cannot load.
- A hairline keeps white flags visible on light surfaces.
- Served by [flagcdn.com](https://flagcdn.com) (Flagpedia), free and without a key; or
  from your own server with `baseUrl`.

## Privacy

Each flag is an image loaded from flagcdn.com, so the visitor's browser contacts that
service. To keep every request on your own domain, copy the SVGs (from flagcdn or the
`flag-icons` package) to your server and set `baseUrl`.

## Accessibility

The flag is an image named after the country. A flag is not a language: to pick a
language, write its name ("Français"), with or without a flag.
