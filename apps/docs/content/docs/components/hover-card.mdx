## Features

- Opens after 500 ms on hover, closes 200 ms after the pointer leaves.
- Opaque glass, an optional arrow; flips and shifts to stay on screen.
- The trigger stays a plain link.
- Built on [Radix Hover Card](https://www.radix-ui.com/primitives/docs/components/hover-card).

## Accessibility

The card is for sighted pointer users only: keyboard focus and screen readers do not
open it. Never put information or actions that exist nowhere else in it; the link it
belongs to must lead to the same content.
