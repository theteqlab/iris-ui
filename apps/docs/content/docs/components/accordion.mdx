## Features

- One section open at a time (`type="single"`, `collapsible` to close it) or several
  (`type="multiple"`).
- Each header is a real heading (`<h3>` by default, `level` to change it).
- The panel opens with a height animation, removed with reduced motion.
- Arrow keys move between headers.
- Built on [Radix Accordion](https://www.radix-ui.com/primitives/docs/components/accordion).

## Anatomy

```tsx
import { Accordion, AccordionContent, AccordionItem, AccordionTrigger } from "@irisui/ui";

export default () => (
  <Accordion type="single">
    <AccordionItem value="…">
      <AccordionTrigger />
      <AccordionContent />
    </AccordionItem>
  </Accordion>
);
```

## Accessibility

Follows the [WAI-ARIA accordion pattern](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/).
