## Features

- The button shows the password as text, then hides it again.
- Hidden again when the form is submitted, so the browser never saves it as text.
- `autoComplete` is `current-password` by default; `new-password` to create one.
- Same sizes, invalid state and [Field](/docs/components/field) support as
  [Input](/docs/components/input).
- Button labels from `LocaleProvider` (English and French built in).
- Built on [Radix Password Toggle Field](https://www.radix-ui.com/primitives/docs/components/password-toggle-field) (preview).

## Usage

```tsx
import { Field, FieldLabel, PasswordToggleField } from "@irisui/ui";

export default () => (
  <Field>
    <FieldLabel>Password</FieldLabel>
    <PasswordToggleField />
  </Field>
);
```

## Accessibility

The button is labelled "Show password" or "Hide password" and keeps the focus on the
input's side. Its 36 px target sits inside the field.
