## Features

- One pressed item at most (`type="single"`) or several (`type="multiple"`).
- Arrow keys move between items; <kbd>Tab</kbd> enters and leaves the group.
- One `size` for every item.
- Built on [Radix Toggle Group](https://www.radix-ui.com/primitives/docs/components/toggle-group).

## Anatomy

```tsx
import { ToggleGroup, ToggleGroupItem } from "@irisui/ui";

export default () => (
  <ToggleGroup type="single">
    <ToggleGroupItem value="…" />
  </ToggleGroup>
);
```

## Accessibility

Name the group with `aria-label`. With `type="single"`, the items are `radio` buttons in
a `radiogroup`; with `type="multiple"`, `button`s with `aria-pressed`.

<KeyboardTable
  keys={[

    ["ArrowLeft", "Moves focus to the previous item."],
    ["Home", "Moves focus to the first item."],
