## Features

- Pressed, it turns solid ink; released, it is transparent.
- 36, 44 and 56 px heights, square when it holds an icon alone.
- Controlled or uncontrolled.
- Built on [Radix Toggle](https://www.radix-ui.com/primitives/docs/components/toggle).

## Usage

```tsx
import { Toggle } from "@irisui/ui";

export default () => <Toggle>Show grid</Toggle>;
```

## Accessibility

A `button` with `aria-pressed`. With an icon alone, name it with `aria-label`. For an
option that applies at once in settings, prefer a [Switch](/docs/components/switch).
