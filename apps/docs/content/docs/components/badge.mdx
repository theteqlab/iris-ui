## Features

- Looks `holo`, `glass`, `solid` and `outline`, with the same tones as Button.
- Status badges (`success`, `warning`, `danger`, `info`, `neutral`) in the status colours
  shared with Alert and Toast.
- An optional dot, in the text colour.

## Usage

```tsx
import { Badge } from "@irisui/ui";

export default () => (
  <Badge look="outline" tone={3} dot>
    Online
  </Badge>
);
```

## Accessibility

A badge is plain text. When its colour carries meaning (paid, failed, online), say it
in the text too: colour alone is not enough. Every status passes WCAG AA contrast in
the 8 palette × mode combinations.
