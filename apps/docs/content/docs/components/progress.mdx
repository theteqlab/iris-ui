## Features

- Determinate (`value` from 0 to `max`) or indeterminate (`null`: the film slides).
- The holographic film by default, or a tone.
- 20 px rail; no animation with reduced motion.
- Built on [Radix Progress](https://www.radix-ui.com/primitives/docs/components/progress).

## Usage

```tsx
import { Progress } from "@irisui/ui";

export default () => <Progress aria-label="Upload" value={60} />;
```

## API reference

### Progress

<PropsTable type="ProgressProps" pick={["value", "max", "tone", "getValueLabel"]} />

| Data attribute | Values                                       |
| -------------- | -------------------------------------------- |
| `data-state`   | `"loading" \| "complete" \| "indeterminate"` |
| `data-value`   | The value                                    |
| `data-max`     | The maximum                                  |

## Accessibility

`role="progressbar"` with `aria-valuenow` and `aria-valuemax`. Name it with
`aria-label` or `aria-labelledby`.
